# Magic Hour

Create AI images and videos inside Power Automate and Azure Logic Apps. Each create action returns a project ID. Use the matching project action to retrieve status and output URLs.

## Authentication

Use a Magic Hour API key from [Magic Hour API settings](https://magichour.ai/settings/api-keys). Enter the raw key; the connector supplies the `Bearer` prefix.
